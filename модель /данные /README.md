# Классификация возрастных групп пользователей

Проект машинного обучения для предсказания возрастной категории пользователей на основе их логов интернет-активности (категории сайтов, время суток, используемые девайсы).

## Описание задачи
Модель анализирует поведение пользователей и классифицирует их на 5 возрастных групп. Проект включает в себя полный цикл ML-разработки: от Feature Engineering до настройки гиперпараметров и калибровки вероятностей.

## Технологический стек
* **Язык:** Python
* **Библиотеки:** Pandas, Scikit-learn, NumPy, Matplotlib, Seaborn, Joblib
* **Модели:** Logistic Regression, Support Vector Classifier (SVC)
* **Инструменты:** GridSearchCV, RFECV, Pipeline, CalibratedClassifierCV

## Ключевые этапы
1. **Feature Engineering:** Агрегация сырых логов посещений, расчет долей интернет-активности по времени суток (`time_ночь_share` и т.д.) и категориям сайтов.
2. **Предобработка:** `MinMaxScaler`/`StandardScaler` для числовых признаков, `OneHotEncoder` для категориальных.
3. **Отбор признаков:** Использование `RFECV` для отсеивания информационного шума (сокращение признакового пространства до 30 оптимальных предикторов).
4. **Моделирование и Тюнинг:** Обучение `SVC` с RBF-ядром, настройка гиперпараметров через `GridSearchCV` с кросс-валидацией на 5 фолдах.
5. **Калибровка:** Приведение уверенности модели к реальным вероятностям с помощью метода Платта (`CalibratedClassifierCV`).

## Результаты
Финальная модель (SVC с ядром RBF) показала на отложенной тестовой выборке следующие результаты:
* **F1-macro:** 0.8805
* **Precision-macro:** 0.8750
* **Recall-macro:** 0.8870

Модель уверенно превзошла Baseline (0.20) и требуемый заказчиком порог (F1-macro $\ge$ 0.75). Наиболее сильными предикторами оказались доли ночной активности и посещения специфических категорий сайтов.
